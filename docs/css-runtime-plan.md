# CSS 语义修复与运行时延迟创建

2026-10-14，按用户确认的方向实施，仍只在 fixtures 验证，不建立正式 UI 组件。

## 组合契约

参考 [Emotion cx 实现](https://github.com/emotion-js/emotion/blob/main/packages/css/src/create-instance.ts)：可识别样式按输入顺序合并，未知普通类名原样保留。Emotion 也不会反向读取任意外部样式表。这里用 CssClass 的结构化描述保留对应信息，并继续传递 Vue 实例的绑定身份，不建立会混用不同实例 getter 的全局类名表。

同一选择器、条件路径和属性，后面的有效声明获胜，包括覆盖前面的 important 声明；undefined 回退，null 清除。普通外部类名仍受原生 CSS specificity、layer 和 important 约束，明确配置的宿主 layer 用于外部样式协作，不靠 HTML class 顺序承诺不可实现的效果。

## 动态值与优先级

- bx 保持独立捕获、最终消费时读取及覆盖后不执行的契约；模板先组装成完整 CSS 值，再绑定变量。放弃每个插值必须独占 CSS 变量的实现限制，避免单位、字符串及 URL 被破坏。
- 完整结果是 CSS-wide keyword 时直接发射原生值；模板片段按普通字符串语义组合，不单独把引号内的 inherit 等文字当成属性关键字。
- 使用现有 CSS tokenizer 提取末尾顶层 important，保留为声明优先级；不把它塞进变量值。引号、函数、注释及大小写按 token 处理。关键帧检查同一优先级信息。
- 以浏览器计算值验证 transform、content、background-image、优先级切换、外部覆盖与 SSR/hydrate，不能只检查生成字符串和变量数量。

## 延迟创建和复用

不改变普通 JavaScript 已执行的属性调用；轻量不可变链继续即时建立。大型数据和消费工作延后：

1. 系统关键字按实际访问的属性组创建，同一组共享不可变缓存；生成数据复用公共关键字集合，不在模块加载时铺开全部对象。
2. 上下文的默认作者首次 useCss 时创建；同一上下文按真实来源对象/Ref 弱缓存作者，provideTheme 注册后子树获取同一实例。不同上下文及请求保持隔离。
3. 主题属性组按首次访问验证，不为未使用的 getter 组执行工厂。显式 keywords 仍绑定其来源，区域作者仍取最近的提供值。
4. cx 只在声明时快照组合输入，首次消费才展开链；静态解析结果和选择器计算按安全边界复用，缓存不保留动态绑定值或跨请求状态。

不采用每个样式对象一套容器、全局扫描 CSSOM 或新的 variants DSL。先用小型实例/缓存断言证明优化有效，再用 CI 的生产入口体积和完整浏览器覆盖观察成本。

## 分阶段验证

先关闭上一轮严格类型检查失败；然后分别提交动态值/优先级及延迟创建。每轮本地做受影响文件 LSP 和少量短测，提交前核对上一轮真实 CI。完整生成一致性、类型、构建、声明消费、浏览器与长测试继续由 CI 执行。
